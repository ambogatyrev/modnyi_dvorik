# Модный дворик (Modnyi Dvorik)

A women's store application for accessories, cosmetics, and care products.

## Project Structure

This is a monorepo containing the following subprojects:

```
modnyi_dvorik/
├── mobile/              # Flutter mobile application (iOS + Android)
└── backend/             # Backend services (planned)
```

## Mobile Application

The mobile app is built with Flutter and supports both iOS and Android platforms.

## Backend

The backend directory is currently a placeholder for future backend services.
